# Saptarshi Dey — Portfolio

A responsive, single-page portfolio matching the supplied design direction: dark, cinematic, technical, and focused on backend engineering, payments, distributed systems, scale and ownership.

## Zero-build setup
This version is intentionally dependency-free. You can simply open `index.html` in a browser.

For local development with a static server:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Deploy
Upload the folder to any static host such as GitHub Pages, Netlify, Vercel, Cloudflare Pages, S3, or your own server.

## Customize
- `index.html` — content, links and sections
- `styles.css` — all visual styling and responsive behavior
- `script.js` — mobile navigation, scroll effects and reveal animations

The About section currently uses an initials-based visual instead of a real photograph so you can replace it with your own image later.
